# 개미수열 (`algorithm/`)

**대시보드를 끝낸 뒤에 한다.** 지금은 `package.json`과 README 뼈대만 있고 소스가 없다.

착수 전에 아래 "이 문제의 진짜 난이도는 길이다"를 먼저 읽는다 —
접근 방식을 정하지 않고 시작하면 다시 짜게 된다.

## 문제

양의 정수 `n` (3 < n < 100)이 주어질 때, 개미수열(Look and Say) `n`번째 항의
**가운데 두 자리**를 반환한다.

```
L1 = 1
L2 = 11        (1이 한 개)
L3 = 21        (1이 두 개)
L4 = 1211      (2가 한 개, 1이 한 개)
L5 = 111221
```

## 이 문제의 진짜 난이도는 길이다

수열은 **콘웨이 상수(≈1.3036)** 비율로 길어진다. 실측·추정:

| n | 길이 | 문자열로 들고 있으면 |
| --- | --- | --- |
| 10 | 20 | — |
| 20 | 302 | — |
| 30 | 4,462 | — |
| 40 | 63,138 | — |
| 45 | 237,746 | 0.5 MB |
| 60 | ≈1.3 × 10⁷ | 25 MB |
| 80 | ≈2.6 × 10⁹ | **5 GB** |
| 99 | ≈3.9 × 10¹¹ | **약 784 GB** |

**`n=99`를 문자열로 만드는 건 불가능하다.** 문자열을 이어붙이는 순진한 구현은
n이 60 근처만 가도 죽는다. 그런데 문제는 3 < n < 100 이므로 **99가 입력 범위 안에 있다.**

이게 이 과제가 숨겨둔 진짜 문제다. "만들어서 가운데를 자른다"가 성립하지 않는다.

## 그래서 어떻게 푸나 — 결정해야 할 것

아래 중 하나를 고르고 **왜 골랐는지 README에 쓴다.** 이 판단이 이 과제의 채점 포인트다.

### 후보 A. 그냥 만든다 (n 상한을 인정)

문자열로 생성하고, 감당 못 하는 n에서는 명시적으로 실패시킨다.
- 장점: 코드가 10줄. 정확하다.
- 단점: **문제가 허용한 입력(n≥60 근처)을 못 푼다.** 과제 요구를 못 채운다.
- 이걸 고른다면 한계를 README에 정직하게 쓰고, 왜 그 이상이 불가능한지 수치로 보인다.

### 후보 B. 코사인 정리 — 필요한 부분만 생성

가운데 두 자리만 필요하므로 **전체를 만들지 않는다.**
- 개미수열은 콘웨이의 **audioactive decay** 성질이 있다: 어느 시점 이후 수열은
  92개의 독립 "원소(element)"로 분해되고, 각 원소는 자기들끼리만 전이한다.
- 원소별 **개수 벡터**만 행렬로 굴리면 길이는 O(1) 메모리로 정확히 구할 수 있다.
- 가운데 위치를 알면, 그 위치가 어느 원소에 속하는지 역추적해 해당 부분만 전개한다.
- 장점: n=99도 푼다. 이 문제의 정석 해법이다.
- 단점: 92-원소 테이블이 필요하고 구현이 무겁다.

### 후보 C. 길이만 먼저 구하고 필요한 구간만 재귀 전개

92개 원소 테이블 없이도 가능한 중간 지점:
- `len(n, 시작문자)` 를 메모이제이션으로 구한다 — 한 자리가 n단계 후 몇 자리가 되는지.
- 가운데 인덱스를 알면 그 인덱스가 속한 가지만 따라 내려가며 전개한다.
- 전체를 만들지 않고 **필요한 경로만** 판다.
- 장점: B보다 훨씬 짧다. n=99도 이론상 가능.
- 단점: 길이가 BigInt 범위로 커지므로 인덱스 연산을 BigInt로 해야 한다.

> **추천: C부터 시도.** B의 원소 테이블 없이 같은 결과를 얻고 코드가 훨씬 짧다.
> C가 막히면 그때 B로 간다. A는 요구사항 미달이라 최후 수단이다.

## 확인해야 할 것 (구현 전에)

- **"가운데 두 자리" 정의.** 길이가 홀수면 어디가 가운데인가?
  - `L4 = 1211` (길이 4) → 가운데 두 자리는 `21`
  - 길이가 홀수인 항이 존재하는가? (L1=`1` 길이 1, L2=`11` 길이 2 …)
  - **홀수 길이일 때의 규칙을 정하고 테스트로 고정한다.** 이게 애매하면 답이 갈린다.
- 반환 타입 — 숫자인가 문자열인가. `'01'` 같은 앞자리 0이 나올 수 있는가?
- 입력 검증 — 범위 밖(n≤3, n≥100)은 어떻게 하나. 예외인가 특수값인가.
