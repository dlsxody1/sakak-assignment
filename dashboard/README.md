# 건강검진 대시보드

CANDiY API를 연동해 건강검진 결과를 시각화하는 SPA.

## 실행

```bash
pnpm install
pnpm dev
```

## 스크립트

| 명령 | 설명 |
| --- | --- |
| `pnpm dev` | 개발 서버 |
| `pnpm build` | 타입체크 + 프로덕션 빌드 |
| `pnpm test` | 테스트 |
| `pnpm lint` | oxlint |

## 기술 스택

TypeScript / React 19 / Vite / TanStack Router / TanStack Query / Tailwind CSS v4 / Vitest
